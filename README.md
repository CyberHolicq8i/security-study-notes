# Security Study Notes

Learning-in-public notes from CompTIA and cybersecurity fundamentals study — TryHackMe room writeups, exam-objective checklists, and summaries as I work through Security+, Network+, and A+.

## Structure

- `security-plus/` — SY0-701 domain notes (General Security Concepts, Threats & Vulnerabilities, Security Architecture, Security Operations, Program Management)
- `network-plus/` — N10-009 domain notes
- `a-plus/` — 220-1201 / 220-1202 domain notes
- `tryhackme/` — room writeups and technical vocabulary notes

## Why this exists

Documenting study as it happens is stronger evidence of hands-on learning than a certificate alone, and it's a running record for interview prep — concrete examples of concepts explained in my own words rather than recalled cold.
